# 小红书创作站产品规格

本文件描述当前产品应有的行为和验收标准，不代表所有真实环境均已验证。操作见 [使用指南](USER_GUIDE.md)，实现与接口见 [开发指南](DEVELOPMENT.md)，完成度见 [TASK_STATE](../TASK_STATE.md)。

## 1. 目标与边界

小红书创作站帮助用户用自己的文字素材创作小红书草稿，并结合经确认的账号定位和热门文字写法，完成选题、文案、核对、编辑、保存及可选封面。支持手动分阶段操作和单次授权的自动化流程，保持桌面三栏工作台。

个人素材提供本篇事实，热门参考用于选题和表达，账号档案约束长期定位与语气。不得把参考作者的经历、数字当作用户经历，也不得把账号历史经历直接写成本篇新发生事实。内容应具体、有依据，避免虚假体验、空洞夸张和无依据的医疗 / 金融承诺。

当前只处理文字素材和笔记文字正文，不含 PDF、Word、图片 OCR、视频字幕或评论；不做自动发布、点赞、评论、收藏、关注、私信和后台批量采集。

## 2. 触发与身份确认

搜索、读取、素材整理、模型生成、模型决策和 CLI 检测均须由用户主动点击触发。搜索结果不自动加入热门参考；加入必须来自手动勾选 / 粘贴，或本次“自动化生成”的模型选择。自动化只授权当前勾选的串行流程，不做后台轮询或自动重试。

项目品牌统一为“小红书创作站 / XHS Creator Station”。侧栏、身份说明和笔记预览显示当前已确认连接账号的真实昵称、头像和粉丝数，不固定个人名字；未连接、头像缺失或加载失败有明确占位。预览另一账号资料时不提前切换身份。

## 3. 账号档案

### 3.1 连接、取样与正文

用户输入完整主页链接或 24 位十六进制账号 ID，读取资料后确认使用该账号，暂不解析短链接。账号身份显示不依赖分析完成。

填写运营目标及用户确认的身份、事实和长期要求；同步不得覆盖它们。“一键读取并分析”串行获取作品、选样、读正文、分析；手动路径是“同步作品列表”→ 勾选样本 →“读取所选并分析”。

作品每页最多 30 条，本轮可主动加载最多 3 页。默认结合近期、相对高互动和普通作品推荐约 10 篇，手动可选 1–12 篇，显式排除同步后仍生效。保留已读正文、原文备份与用户反馈，不静默重读；重读由用户逐篇触发。

读取必须核对笔记编号及可获取的作者编号，身份不符的内容不得关联为样本。所选作品缺少正文或超预算时禁止分析；超长原文完整保留，可精简、恢复或取消选择。局部读取失败保留其他成功结果；未登录、验证、限流或 CLI 环境异常停止本轮剩余读取。

### 3.2 分析、审核与版本

分析包含概况、定位、读者假设、内容方向、表达习惯、边界、待验证建议、原文依据与更新建议。每条依据须属于所选作品，并在其标题或正文中存在真实连续引句。

缺失指标保持未知，不根据粉丝数推断受众属性，不把高互动与写法的相关性写成因果结论。结论只覆盖已获取文字，供用户审核。

“账号档案审核”始终位于操作按钮下方、历史列表上方；区分未连接、未分析、正文未就绪、进行中、失败、待确认、过期和已确认，提供对应下一步。分析失败在本区显示原因；成功保存候选后自动定位到表单，可编辑、核对引文、查看更新建议与字段差异。

“确认并保存正式档案”须在用户确认且数据库事务成功后启用正式版本，保留历史。输入样本、正文、目标、事实、反馈等变化使旧候选过期，禁止直接确认。仅头像或抓取时间变化不使有效候选过期；昵称、简介等分析资料变化仍需重做。

“同步并生成更新建议”只产生新候选，经再次确认才成为下一版。旧正式版本在失败或候选待审期间继续有效。“账号数据已保存”与“已分析 / 已确认”分别提示。

### 3.3 在草稿中使用

新草稿默认采用当前正式版本，在首次用户生成或模型决策时保存版本快照；仅恢复账号库不自动新建空稿。已有草稿保留快照，主动“本篇使用最新确认版本”才换版，并标记旧结果需重新核对。

支持延续风格、尝试新方向、本篇关闭三种模式，进入模型上下文及结果过期判断。示例人设可被正式定位替代，用户自填人设与本篇要求保留。未确认候选不进入创作；账号档案不能替代本篇个人素材或热门参考，不把整个样本库发给写作模型。

账号库按账号保存，确认切换不删除原库，重新连接可恢复。头像使用公开地址、no-referrer 和域名过滤，地址不进入分析模型上下文。

## 4. 本篇输入与个人文字素材

人设、关键词、创作要求、必须保留内容随草稿保存，要求从选题阶段贯穿后续生成和决策。建议关键词只填入输入框，不自动搜索。

支持粘贴及 TXT / MD / Markdown 多文件导入，兼容 UTF-8 与 Windows 常见 GBK 编码。保存唯一编号、标题、完整原文和勾选状态；未勾选文字不发模型，未加入的粘贴输入也保存，生成前提醒先加入。

超出条数、单条或文件预算时明确拒绝；超过本篇合计预算的条目可完整保存为未勾选，禁止静默截断。

“整理素材”返回摘要、关键信息、建议关键词和待补充信息。关键信息必须绑定有效素材编号及真实原文引句。摘要可编辑确认；只有已确认且原文未变的摘要可作补充，所有生成和决策仍读取完整勾选原文。整理并非手动创作的强制前置步骤。

## 5. 热门文字参考

搜索展示标题、摘要 / 片段、标签、已获取的互动、来源、关键词和检索时间。手动勾选后“加入并读取正文”，或粘贴参考文字。热门参考随本篇草稿保存，不静默加入全部搜索结果。

区分搜索摘要、CLI 读取正文与手动提供正文。单条、批量补读和“读取正文并分析写法”均只读所选且无正文的条目，串行显示进度，不覆盖已有或手动正文。标题或摘要不得当作读取成功的全文。

读取复用 CLI 自身登录态与访问上下文，不读取或转发 Cookie / xsec_token；校验返回笔记身份。失败可重试、补充或删除，保留成功正文；全局登录、验证、限流、运行环境或旧后台错误停止本批。

原文、来源、读取时间和备份随草稿保存，超限完整保留并提示精简；可编辑正文或恢复读取原文，旧写法分析随之失效。模型仅收到当前选用文字与必要来源，不收到备份、读取错误或凭据。

参考写法分析给出标题、开头、结构、结尾与适合本篇的组织建议。任何已加入参考没有正文时，界面阻止写法分析、选题、文案与封面 Prompt 生成，不静默回退摘要。底层兼容旧摘要请求时，必须明确标注仅有摘要，不推断未读结构。

## 6. 生成、编辑、核对与封面

生成上下文包括人设、关键词、要求、必须保留内容、完整勾选素材、有效的已确认摘要、当前参考与分析，以及适用的正式账号快照。个人素材或热门参考至少有一类。

| 阶段 | 预期结果与约束 |
| --- | --- |
| 选题 | 10 个候选，含标题、角度、受众、推荐理由与内容重点；使用个人素材时返回有效素材编号和待补充信息 |
| 文案 | 基于所选选题生成 5 篇，含标题、正文、封面方向、素材编号及待补充信息；正文含 `#话题名称[话题]#` 格式话题 |
| 素材核对 | 对所选文案返回有依据、待确认或缺失及遗漏点；“有依据”必须含有效素材编号和真实引句，不能宣称独立证实事实 |
| 封面 Prompt | 所选文案对应 5 份；默认无真人、脸、手和动物，可用静物、植物或花材 |
| 封面图 | 用户选 Prompt 后按独立图片通道生成 PNG；失败保留 Prompt，保存时备份图片 |

所选文案支持改标题和正文、同步预览、复制和 Markdown 导出。导出只含所选标题正文，不含素材、核对或密钥。编辑文案清理旧封面方案；上下文或正文变化保留原文字结果并提示失效 / 重新核对，不能把旧报告当成新检查。

自动化决策必须选有效候选：参考选 1–8 项，选题、文案和封面 Prompt 各选 1 项；重复、无效、空选或数量错误须停止，不能悄悄代选。

## 7. 自动化

要求人设、关键词和本篇创作要求。默认开启热门参考、关闭封面；关闭参考需有个人素材且不执行 xhs，文字模式不要求图片配置。

本次流程：按需整理素材 → 搜索并选择参考 → 读取所选正文 → 写法分析 → 生成并选选题 → 生成并选文案 → 有个人素材时核对；勾选封面才继续生成并选 Prompt → PNG。

重新自动化会重置本次网络参考与生成结果，保留个人素材。失败停止后续并保留本次成功阶段、选择与原文，显示具体阶段及原因，用户可修复后手动继续；不会后台自动重试。正文未齐或超预算时停在读取阶段。

## 8. 保存、删除与恢复

草稿与账号库分别持久化到浏览器 IndexedDB，模型配置留在原 localStorage；项目快照不得包含模型密钥。保存成功须等数据库事务完成，失败明确提示。

草稿包含完整输入、未加入素材、分析及确认态、参考、候选、所选项、编辑内容、档案快照与封面 PNG。新建和切换前保存当前稿，切换中禁止冲突编辑；支持素材复用新稿。首次沿用旧人设、关键词和撰写思路，不伪造旧内存草稿的恢复。

草稿删除入口独立于打开，软删除后从正常列表隐藏，可撤销或从“最近删除”恢复全部数据；项目与索引原子更新，迟到保存不得复活。删除当前稿打开剩余稿，删除最后一稿或首次无记录时保持未保存工作区，不自动产生空稿。

参考右上方始终有删除入口，删除同步取消搜索勾选、清理旧写法分析，保存完整条目与原顺序。“已删除参考”可恢复，刷新仍有效；恢复校验预算，同编号不重复。删除 / 恢复失败保留原列表，不触发搜索、CLI 或生成。

封面备份失败仍保存文字，但明确区分部分保存。正常关闭不删除已保存数据；跨浏览器、地址、无痕模式或清除站点数据不保证可恢复，无云同步。改品牌不能改历史存储命名空间，Git 备份不含浏览器数据。

## 9. 统一限制与等待

以下均为字符数，文件大小另计；超限不静默截断。

| 输入 | 上限 |
| --- | --- |
| 人设 / 关键词 | 1000 / 160 |
| 本篇创作要求 / 必须保留内容 | 4000 / 2000 |
| 个人素材 | 每稿 12 条，单条及勾选合计 20000；单文件 160000 字节 |
| 素材摘要 | 4000 |
| 热门参考 | 每稿 8 条，单条 6000、合计 24000 |
| 账号作品列表 / 样本 | 每页 30，本轮最多 3 页；分析选 1–12 篇 |
| 账号分析正文 | 单篇 6000、合计 40000 |
| 账号目标 / 用户确认事实 / 单篇反馈 | 2000 / 2000 / 1000 |

所有单次模型调用统一最多 15 分钟，涵盖本地 / 云端文字、各类分析、决策与封面生成；提前完成立即返回，不降低用户思考强度、不截断输入。此上限不是整个自动化的总时限，也不保证上游会持续运行或一定成功。

账号分析显示篇数、字符数和已等待时间；超时保留正文及原正式版本。正文齐备、无待确认结果时，“分析已读正文”只重试模型，不重新同步读取。XHS 命令、CLI 检测与图片文件下载有独立时限，详见开发指南。

## 10. 错误与验收关注

配置缺失、密钥无效、CLI 不可用 / 能力不符、登录 / 验证 / 限流、网络、超时、返回非 JSON / 非 PNG、身份不符、正文为空、结构或引文无效、保存失败，都须显示可理解原因及下一步。上游错误保留脱敏后的具体信息，不能把异常退出一律报成 JSON 错误。

升级后固定地址仍运行旧后台时，应提示保存、停止原窗口再启动；不得静默复用或主动终止用户进程。启动兼容探测为本地只读请求，不执行 CLI、模型或平台访问。

验收须覆盖成功流程及以下易错场景：输入超限不丢原文；正文缺失阻止后续；模型失败保留阶段结果；候选过期不能确认；数据库失败不显示成功；旧稿不自动换版；刷新后删除仍生效且可恢复；最后一稿删除不产生空稿；旧后台被识别；新账号预览不提前替换当前身份。具体验证方法和当前实测范围分别在开发指南与 TASK_STATE。
