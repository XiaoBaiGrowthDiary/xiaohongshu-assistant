# 账号档案操作指南

## 首次建立

1. 停止旧启动窗口后重新启动薄荷工坊。新启动器会检查账号接口，避免继续复用旧后台。
2. 左侧点击“我的账号”。输入 `https://www.xiaohongshu.com/user/profile/账号编号` 形式的完整主页链接，也支持直接输入 24 位账号编号；暂不解析短链接。链接查询参数不会进入保存的账号来源。
3. 点击“读取账号资料”，检查昵称、简介、粉丝数和编号，点击“确认使用这个账号”。这一步只确认账号，尚未生成正式档案。
4. 填写接下来的运营目标，以及你确认的身份、事实和长期要求，两项各最多 2000 字符。
5. 配置右侧文案模型，点击“一键读取并分析”。本次点击授权串行读取作品列表、选择样本、读取正文、分析账号。默认综合近期、相对高互动与普通作品选择约 10 篇；最多勾选 12 篇。
6. 在按钮下方、历史作品列表上方的“账号档案审核”区查看当前进度和结果；成功后会自动定位。在待确认档案中查看账号概况、定位、读者假设、内容方向、表达习惯、边界和待验证建议。展开原文依据核对引句，可以编辑分析内容。
7. 点击“确认并保存正式档案”。只有数据库保存成功后，正式版本才生效；失败可重试，旧版本继续保留。

## 样本和读取失败

先点击“同步作品列表”可以自行挑选样本，再点击“读取所选并分析”。每次列表最多 30 条，“加载更早一页作品”允许本轮最多查看 3 页。排除的作品在同步后保持排除，已读正文和你的作品反馈保留。新增作品会参加下一轮样本推荐。

每篇用于分析的正文最多 6000 字符，所选正文合计最多 40000 字符。超过预算时完整原文仍保留，可编辑精简、取消勾选或恢复原文。作品的评价 / 发布反馈可填写你自己的观察，每篇最多 1000 字符。

读取失败会保留原因与其他已读结果。可以单独重新读取、手动补充文字或取消勾选。任何所选作品缺少正文时，不调用账号分析模型。需要登录时请主动运行 `xhs login`；需要验证、网络限流或 CLI 环境异常时按提示处理后重试。应用不会读取或保存 Cookie。访问上下文保留在 CLI 内部，账号正文读取前会刷新相应列表并校验返回身份。

本轮分析不包含图片内文字、视频字幕和评论。缺失的阅读量、互动数据或涨粉来源保持未知；相对高互动只用于挑选比较样本，不能证明某种写法导致成功。读者画像与改进方向属于待确认判断。

## 创作和更新

确认后，新草稿默认使用当前正式档案；原来仍显示示例人设时会采用档案定位，自己填写的人设和本篇创作要求仍然保留。档案约束定位和表达，个人素材继续提供本篇事实；仅有账号档案不能代替本篇素材或热门参考。

“本篇使用账号档案的方式”支持延续账号风格、尝试新方向、本篇不使用。首次创作或模型决策时将正式档案版本快照存入当前草稿。全局档案更新后，已有草稿继续使用快照；点击“本篇使用最新确认版本”才切换，并提示旧创作结果需要重新核对。

有新作品或反馈后，点击“同步并生成更新建议”。同步保留你填写的目标和确认事实；已读正文不会静默重读，可对改过的作品主动点击“重新读取此篇正文”。新分析先进入待确认区，展示模型更新建议和每个字段的前后差异。再次确认才新增正式版本。样本、正文、反馈或目标变化后，待确认分析会过期，需要重新分析。

## 保存范围

账号库独立于草稿，包含历史文字、原文备份、反馈、待确认分析和正式版本。确认另一个主页可以切换账号，再次连接原主页可恢复该账号记录。草稿保存它使用的档案快照，不保存整份账号样本库或模型密钥。

以上数据保存在当前浏览器和站点地址的 IndexedDB；等待“账号数据已保存”后再关闭页面。更换浏览器、端口或清除站点数据不会自动同步。没有后台自动读取、定时采集或自动发布。

## 分析等待和重试

账号分析、选题、文案、其他文字分析、模型决策和封面生成，均按单次模型调用最多等待 15 分钟。任务提前完成立即返回；这个等待上限不会修改当前配置的推理强度，也不保证模型或上游网络一定能在期限内完成。

账号审核区显示本次分析的篇数、字符数和等待时间。已读正文、目标和反馈会保留；超时后无需重新同步作品。完整正文就绪、尚无待确认结果时，直接点击“分析已读正文（无需重新读取）”重试。也可以主动减少勾选或选择其他文案通道。不做后台自动重试。

如果旧提示仍在约 3 分钟出现，先保存账号数据并停止原启动窗口，再重新启动；只刷新页面不能保证后台更换。启动器会检查后台的等待设置，避免复用旧版本。

## 关闭和重新启动

IndexedDB 是浏览器替本网站保存在电脑上的本地数据库。正常关闭网页、薄荷工坊、Codex assistant 或 PowerShell 不会删除已保存的数据；PowerShell 只负责运行服务。重启后继续用同一浏览器的普通窗口打开同一个固定地址 `http://127.0.0.1:52880`，会恢复账号资料、作品、待确认分析和正式版本。

等待“账号数据已保存”再关闭。使用无痕窗口、清除站点数据、更换浏览器或换成另一个地址 / 端口，都可能无法恢复原数据。它不位于项目文件夹中，也不随代码推送到 GitHub。
