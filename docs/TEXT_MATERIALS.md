# 文字素材操作指南

本轮升级的目标是：用你提供的事实、经历和观点确定内容，用热门文字参考改善选题与表达。

## 准备素材

在“我的素材”粘贴文字，起一个便于辨认的标题，点击“加入我的素材”。也可以选择一个或多个 TXT、MD、Markdown 文件；支持 UTF-8 与 Windows 常见 GBK 编码。文件读取只在浏览器本地进行，点击整理或生成后才向选定的文本通道发送勾选内容。

素材列表中勾选本篇要用的条目。每稿最多 12 条，本篇勾选原文合计最多 20000 字符；超过预算的导入条目会保留为未勾选状态。可展开条目编辑原文，所有修改自动保存。未点击加入的粘贴输入也会保存在当前草稿，开始生成前会提醒先加入。

将经历和数据写在素材区，将读者、语气、篇幅和表达目的写在“本篇创作要求”。“必须保留的内容”可填写重点、限制和不推荐的部分。创作要求最多 4000 字符，必须保留内容最多 2000 字符，超限不会默默裁掉末尾。

## 整理并确认

点击“整理素材”，AI 返回摘要、带原文引文的信息和建议关键词。你可以编辑摘要后确认。系统会核对模型引用的素材编号和引句是否存在于原文，但仍需由你确认模型对事实和观点的解释是否准确。

摘要用于辅助理解；只有确认且原文未变化的摘要才作为补充上下文使用。无论是否整理或确认，生成都会读取选中原文的全部文字。点击建议关键词只会填写关键词，不会自动搜索。

较长的素材可使用 Codex、Claude 或云端 API。前两者使用标准输入传递文字，避免 Windows 命令行长度限制；Kimi 与自定义 CLI 的参数协议如果装不下本次上下文，会明确提示减少勾选或更换通道，不会截断原文。

## 加入热门文字参考

可以搜索热门笔记、勾选并加入参考，也可以主动粘贴参考标题和正文。每篇最多 8 条热门参考，每条正文最多 6000 字符、合计最多 24000 字符。已有条目可展开补充正文或移除。

搜索目前提供标题、摘要、标签和互动数据；“仅搜索摘要”明确表示没有获取全文。补充正文后，模型才会分析你实际提供的文字。本轮不自动打开帖子获取全文，也不分析图片和视频。

点击“分析参考写法”，查看标题、开头、结构、结尾和适合你素材的组织方式。只拿到摘要时，无法判断的结构和结尾应明确标为无法判断。热门作者的经历与数字不能直接变成你的经历。

## 创作、核对和编辑

生成 10 个选题并选择一个，再生成 5 篇文案。选题和文案会标明使用哪些个人素材，并展示模型认为需要补充的信息。使用个人素材时无需强制先搜索热门帖子；原有只使用热门参考的流程仍支持。

在编辑区修改标题、正文，预览会同步更新。修改文案会清除对应的旧封面方案；素材、创作要求或参考变化时，保留文字结果并提示重新核对。

“核对素材与文案”检查经历、数字和必须保留的信息，结果分为“有素材依据”“待确认”“待补充”，并显示支持的原文或遗漏点。它是辅助核对，不代表系统已独立证实全部内容。修改正文或素材后，旧核对结果会提示需要更新。

复制和 Markdown 导出仅包含选中标题与正文，不包含素材原文、核对报告或模型配置。

## 自动化

填写人设、关键词和创作要求后，可直接点击“自动化生成”，本次点击授权所选流程。

- 默认“搜索并参考热门内容”开启；关闭时需要个人素材，且不会调用 xhs。
- 默认“同时生成封面图”关闭；文字模式不要求图片模型配置。
- 系统串行整理素材、选择参考并分析、生成并选择选题、生成并选择文案，个人素材存在时继续核对。用户勾选封面后才继续生成封面方案和 PNG。
- 自动化不会清空你的个人素材；中途失败会保留已完成结果，并显示失败阶段，可以手动继续。

## 保存与恢复

草稿、原文、参考、候选、选择状态、编辑内容和核对信息保存到当前浏览器的 IndexedDB，顶部显示实际保存状态。等到“已保存”后可关闭页面；也可主动点击左侧“保存”。保存错误会明确提示，不会假装成功。

左侧“新建”会先保存当前草稿，再创建新稿。点击已保存项目可以恢复内容；“复用这些素材，新建一篇”会复制素材，供另一个主题继续使用。

生成封面保存时会备份 PNG；备份失败仍保存文字，但会明确提示封面尚未备份。保存位置属于当前浏览器与站点地址，换浏览器或清除站点数据不会自动同步；需要带走的文案可导出 Markdown。

## 从旧版本升级

停止旧启动窗口后重新启动薄荷工坊。原有模型配置继续沿用，首次新工作区会读取旧的人设、关键词和撰写思路。旧版本仅保存在内存的参考和候选无法在升级后找回；升级前请先复制仍需要的生成结果。
