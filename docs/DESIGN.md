# 小红书创作站视觉规范

本文件负责视觉与布局，产品行为见 [SPEC](SPEC.md)，浏览器检查方法见 [DEVELOPMENT](DEVELOPMENT.md)。

## 1. 视觉方向

保持 Pastel 3D Claymorphism：薄荷绿、浅紫、粉、奶油白、浅蓝和浅黄；背景使用很浅的紫粉到奶油渐变。面板大圆角约 24–32px，配柔和外阴影、轻微内高光；按钮为胶囊形，主行动使用项目现有的粉紫或薄荷强调色。

整体像柔和的黏土工作台，同时保证生产力工具的清晰层级与文字可读性。沿用圆润 3D soft icon，不改成营销页 hero、纯聊天界面、深色科技风、玻璃拟态、极简黑白或通用 SaaS 后台；避免装饰卡片过多挤压正文。

## 2. 三栏与滚动

| 栏位 | 内容 |
| --- | --- |
| 左栏 | 品牌、当前账号身份、流程导航、草稿及保存 / 恢复 |
| 中栏 | 概览、账号审核、创作输入、素材与参考、选题文案、编辑预览、封面 |
| 右栏 | 文案 / 图片模型配置、CLI 主动检测、过程状态与错误 |

桌面设计宽度 1440px，外层高度 100vh、不纵向滚动，必要时允许横向滚动。`.sidebar`、`.workspace`、`.config-rail` 分别纵向滚动，滚动条低干扰且可发现；`.app-shell` 保持 overflow 约束。

中栏阶段卡片和结果使用内容驱动高度，不固定高度裁掉底部。顶部四个指标完整露出，预览与封面保持稳定图片比例，互动信息和 Prompt 留在卡片内。窄栏按钮可合理换行，不能重叠、隐藏操作或挤压标题。

## 3. 品牌与账号身份

品牌使用“小红书创作站 / XHS Creator Station”，统一来源为 `shared/branding.mjs`。创作者昵称和头像来自已确认连接账号，不能替换成固定昵称或示例卡通头像。

长昵称保持单行，溢出省略并提供完整 title；身份标签和草稿状态保持单行。真实头像使用 no-referrer；没有地址或加载失败时展示可辨认的文字占位，避免让人误以为加载了另一个账号。

## 4. 组件与反馈

- 面板、输入框、分段选项、候选卡片保持大圆角、柔和阴影和适度留白；沿用全局样式 token。
- 参考、选题、文案、Prompt 有清晰的选中态；空状态紧凑、居中、说明下一步。
- 错误用柔和但醒目的粉红，成功用薄荷绿；同时显示文字状态，不能只靠颜色区分。
- 读取、分析、保存和生成期间显示正在做什么；失败原因与重试入口靠近对应内容，右栏保留最近通道与耗时。
- 账号审核位于操作按钮下方、作品长列表上方。未分析、失败、待确认、过期和正式版本应容易区分，成功后定位可见表单。
- 正文来源、原文依据、超限和旧结果过期提示保持可读；不能把摘要视觉上包装成全文。
- 草稿删除与打开使用独立入口；参考删除始终可见，不遮挡标题或读取状态。

## 5. 资产与封面

| 资产 | 用途 |
| --- | --- |
| `public/assets/notebook-pencil.png` | 顶部概览装饰，当前通过 CSS 遮罩融合 |
| `public/assets/spring-outfit.png` | 默认封面预览 |
| 账号公开头像 URL | 当前连接账号身份 |

新增装饰资产匹配软糖 / 黏土质感和马卡龙色系，不用低质量占位、普通 emoji、ASCII 或粗糙绘图替代。概览装饰如需优化，优先透明背景或干净抠图。

封面默认不出现真人、脸、手或动物，可使用衣物、包鞋、文具、桌面、空间、植物或花材；保留真实静物场景，避免误导效果和夸张前后对比。封面摄影风格可与界面黏土装饰区分。

## 6. 视觉验收

在 1440×900 和 1440×720 或其他较矮视口检查：整页不纵向滚动，三栏独立可达底部；左侧保存、中栏封面、右栏错误均可访问；长昵称、长正文和错误文字不重叠；按钮完整、资源正常、无 Vite / React 错误覆盖层。

保留截图并检查 Console。静态渲染不能证明滚动、点击或真实头像网络加载成功；实际完成范围记录在 [TASK_STATE](../TASK_STATE.md)。
