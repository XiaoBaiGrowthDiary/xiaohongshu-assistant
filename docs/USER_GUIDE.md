# 小红书创作站使用指南

本指南按日常使用顺序说明操作。功能限制与验收规则见 [产品规格](SPEC.md)，技术排查见 [开发指南](DEVELOPMENT.md)，当前开发进度见 [TASK_STATE](../TASK_STATE.md)。

## 1. 启动与升级

电脑需要 Node.js 和 npm。在项目目录双击 Windows 的 `启动小红书创作站.bat` 或 macOS 的 `启动小红书创作站.command`，也可执行 `npm run launch:fixed`。首次缺少依赖时需要联网安装，启动器随后构建并打开 [http://127.0.0.1:52880](http://127.0.0.1:52880)。

使用期间保留服务窗口。关闭时先等待页面保存成功，再在启动窗口输入 `q` 后回车或按 `Ctrl+C`。下次继续使用相同浏览器的普通窗口和相同地址。

升级代码后也按上述方式停止原服务，再重新启动。反复双击或刷新页面可能仍访问原后台；启动器发现接口、模型等待时限或账号资料版本过旧时，会提示重启。不要为解决占用而随意改端口，否则会读到另一份浏览器存储。

## 2. 配置文案、图片和小红书连接

右侧“文案生成”和“图片生成”分别配置。只生成文字时可暂不配置图片通道。

| 选择 | 使用准备 |
| --- | --- |
| 本地 Codex / Kimi / Claude | 先安装并在终端完成该 CLI 的登录或配置，再在页面选择，主动点击“检测本机 CLI” |
| 自定义本地 CLI | 填写命令名或可执行文件绝对路径；命令须符合 [开发指南](DEVELOPMENT.md) 中的 print protocol |
| 云端 API | 填写模型名称、API Key、API Base URL；文案与图片可使用不同服务 |

本地图片通道当前仅支持声明图片能力的 Codex。Codex 文案模型别名留空时沿用 CLI 默认模型；填写具体模型 ID 仅覆盖本次文本模型，思考强度沿用原配置。所有单次模型调用最多等待 15 分钟，提前完成立即返回；整个自动化含多次调用，可能超过 15 分钟。

账号读取与热门搜索需要本机 `xhs` CLI，先在终端执行 `xhs login` 完成登录。应用使用 CLI 自身的登录态，不需要在页面填写 Cookie。只用个人素材写作时，可以跳过小红书连接和账号分析。

模型配置在当前浏览器中自动保存，换浏览器或地址不会自动带过去。Windows 通常可自动找到 npm 安装的 Codex 和 uv 安装的 xhs；路径异常时参阅开发指南。

## 3. 建立与审核账号档案

1. 左侧点击“我的账号”，输入完整的 `https://www.xiaohongshu.com/user/profile/账号编号` 或 24 位十六进制账号编号，暂不支持短链接。
2. 点击“读取账号资料”，核对昵称、头像、简介与编号，再点“确认使用这个账号”。侧栏和笔记预览随即使用该账号信息；这一步尚未建立正式分析档案。
3. 填写“接下来的运营目标”和“你确认的身份、事实和长期要求”。同步作品不会覆盖这两项。
4. 配好文案模型后，点击“一键读取并分析”，本次点击串行同步作品、推荐样本、读取正文并分析。
5. 在按钮下方、历史作品列表上方找到“账号档案审核”。成功后会自动定位；查看概况、定位、读者假设、内容方向、表达习惯、边界和待验证建议，展开原文依据核对引句，按需编辑。
6. 点击“确认并保存正式档案”。数据库保存成功后才成为正式版本；“账号数据已保存”只说明资料落盘，不代表已经分析或确认。

想自行选样本时，先“同步作品列表”，勾选后“读取所选并分析”，最终仍须在审核区确认。无需再找一个单独的“建立档案”按钮。每页最多 30 篇，可主动加载更早作品，本轮最多 3 页；默认综合近期、相对高互动和普通作品推荐约 10 篇，手动可选 1–12 篇。

每篇分析文字最多 6000 字符，合计最多 40000。超限时原文保留，可编辑精简、取消勾选或恢复原文；每篇可补充自己的评价与发布反馈。已读正文不会因同步自动重读，需要更新时主动点“重新读取此篇正文”。

缺少正文时先重试、手动补充或取消勾选，所选作品文字齐备后才能分析。分析超时会保留已读资料；审核区有“分析已读正文（无需重新读取）”时，可只重试模型分析。页面显示篇数、字符数和等待时间，不做自动重试。

### 创作时使用与后续更新

新草稿默认采用当前正式档案；原示例人设会采用档案定位，自填人设和本篇要求继续保留。可选“延续账号风格”“尝试新方向”或“本篇不使用”。首次创作或模型决策时记录版本快照，已有草稿不会因全局更新而自动换版。

有新作品或反馈后，点击“同步并生成更新建议”。新分析先待确认，展示更新建议与字段差异，确认才新增正式版本。样本、正文、反馈、目标等分析输入改变后，旧候选过期，须重新分析。旧正式版本继续保留。

只想修改定位、内容方向或表达方式时，点击审核区的“编辑当前档案”，直接修改副本，不调用模型。副本中的目标、事实也可修改，确认后才同步生效。点“放弃本次修改”会回到原正式版本；刷新可继续未完成的修改。展开正式档案历史后，可把旧版本恢复为待确认副本；确认会追加新版本，不覆盖历史，也不改变旧草稿快照。

历史列表中可单条“删除 vN”，确认后永久删除，至少保留一个正式版本；删除当前版本后使用剩余最新版本，并恢复该版的目标与事实。已有草稿快照保留，版本编号不会因删除而复用。若有基于该版本的待确认修改，先确认或放弃修改后再删除。

需要 AI 重做时，先结束手动编辑，再更新上方目标、事实与样本，点击“重新分析已读正文（无需重新读取）”。覆盖未确认修改前会提示确认；重新读取、同步作品仍由对应按钮主动触发。

旧草稿要跟随更新时，主动点击“本篇使用最新确认版本”，再重新核对旧结果。账号档案提供长期定位与语气，本篇仍须有个人素材或热门参考，历史经历不能直接作为新发生事实。

### 昵称、头像与账号切换

显示名和头像取自已确认连接账号，例如“小白的成长日记”，不固定写死。先预览另一个账号，确认后才切换身份；再次连接原账号可恢复原账号库。

升级前的资料没有头像时，重启新版服务，重新“读取账号资料”并确认即可，无需重新分析。头像缺失或加载失败会显示占位，可再次读取资料刷新。单纯刷新头像不会使仍有效的候选分析过期。

分析仅覆盖已获取的文字；没有返回的阅读、互动、涨粉数据保持未知。读者假设和相对高互动的原因需要你判断，不是已经证实的结论。

## 4. 准备本篇个人素材

填写人设、关键词、“本篇创作要求”和“必须保留的内容”：经历、数据、观点放在素材里；读者、目的、语气、篇幅放在创作要求里。

在“我的素材”粘贴文字和标题，点击“加入我的素材”；也可多选导入 TXT / MD / Markdown，兼容 UTF-8 与 Windows 常见 GBK 文字。每稿最多 12 条，单条和本篇勾选原文合计最多 20000 字符；各项完整限制见 [产品规格](SPEC.md)。

勾选决定本篇使用的素材，未选原文不发给模型。超过本篇合计预算的导入条目可保留为未勾选；单条过长会明确拒绝，不裁掉末尾。尚未加入的粘贴输入也随草稿保存，生成前须先加入。文件读取在浏览器本地进行，整理或生成时才发送本次选中内容。

可点击“整理素材”，检查带引文的信息，编辑摘要后“确认用于本篇”。摘要只辅助理解，生成始终读取完整勾选原文；原文变化后旧摘要失效。点击建议关键词仅填写输入框，搜索仍需主动点击。

多条素材会整理成一份汇总。若模型逐条返回，系统仅在每份分别对应一条选中素材、引句全部有效且合并后未超限时接收；其他情况会说明原因，保留原文和上次成功结果，由你决定是否重试。

当前不支持 PDF、Word、图片和视频导入。长上下文可用 Codex、Claude 或云端文本通道；Kimi / 自定义 CLI 若超出进程参数容量，会提示减少勾选或换通道，不截断后生成。

## 5. 学习热门文字参考

1. 点击“搜索热门内容”，勾选想参考的笔记。
2. 点击“加入并读取正文”，只读取所选且尚无正文的条目，串行显示进度。
3. 展开“查看或编辑参考正文”，核对文字、来源和读取时间，也可打开原帖。
4. 点击分析参考写法，查看标题、开头、结构与结尾建议。

旧稿显示“仅搜索摘要”时，可单条“读取正文”或批量“读取未读正文”；“读取正文并分析写法”会先补读再分析。已有正文或手动补充的文字不会被自动覆盖。

也可在“手动加入文字参考”中粘贴正文。每稿最多 8 条，每条用于分析的文字最多 6000 字符、合计最多 24000。读取超限时完整原文仍保留，先精简或减少参考；可“恢复读取的原文”，编辑后旧写法分析需要更新。

读取范围是笔记文字正文，不含图片内文字、视频字幕和评论。任何已加入参考仍缺少正文时，会暂停写法分析和后续创作，不能把搜索摘要当全文。失败可重试、补充或删除，成功结果保留。

## 6. 生成、核对、编辑与封面

生成 10 个选题，选一项后生成 5 篇文案；候选显示个人素材依据与待补充信息。只用个人素材时无需搜索热门，只用热门参考的流程也可继续。

选择文案，在编辑区改标题、正文，预览同步更新。点击“核对素材与文案”，查看“有素材依据”“待确认”“待补充”及遗漏点；引句校验只证明存在于输入原文，最终真实性仍由你确认。

素材、要求、参考或档案版本变化后，原结果保留并提示重新核对；修改文案会清除旧封面方案。复制和 Markdown 导出仅含选中标题与正文，不带素材、报告或模型配置。

需要封面时，生成 5 份封面 Prompt，再选一份生成 PNG。默认静物方向，不含真人、脸、手和动物，可用植物或花材。生成失败保留 Prompt；草稿保存时会备份 PNG，文字已保存但图片备份失败会单独提示。

## 7. 自动化生成

填好人设、关键词、本篇创作要求，准备素材后，按需勾选流程，再点“自动化生成”：

- “搜索并参考热门内容”默认开启；关闭时需要个人素材，且不调用 xhs。
- “同时生成封面图”默认关闭；不开启就不要求图片配置。
- 流程按需整理素材 → 搜索并由文案模型选参考 → 读取正文并分析 → 生成并选选题 → 生成并选文案 → 有个人素材时核对；勾选封面才继续。

失败会停止并保留已完成结果。修好参考后可手动从分析、选题等阶段继续；再次点击自动化会重新开始本次网络参考与生成结果，个人素材保留。它不会在后台持续采集或自动发布。

## 8. 保存、删除与恢复

草稿保存人设、要求、个人原文、未加入输入、参考、候选、选择、编辑内容、核对和封面备份。等待“已保存”后再关闭，也可点左侧“保存”；失败不会显示成功。

左侧“新建”和项目切换会先保存当前稿；“复用这些素材，新建一篇”可给另一主题沿用素材。

| 要处理的内容 | 操作与恢复 |
| --- | --- |
| 草稿项目 | 条目右侧“删除”，可立即撤销，也可从左侧“最近删除”恢复；删除最后一份后保持空工作区，编辑或主动新建后才产生新稿 |
| 热门参考 | 条目右上方“删除”，同时取消对应搜索勾选、清除旧写法分析；在“已删除参考”恢复完整正文和来源，仍受数量与文字预算约束 |

展开“最近删除”或“已删除参考”，可单条“永久删除”，也可清空该区域。确认框会说明对象、数量和不可恢复性；取消不会删除。草稿清空包括这些已删除草稿的素材、结果和本地封面备份；参考清空仅处理当前草稿的已删除参考，正在使用的内容和账号档案保留。保存或删除失败会提示原因，不显示为成功。

账号库独立保存资料、作品正文、备份、反馈、候选分析和正式版本历史；草稿只保存所用档案快照。模型密钥不会进入这两类记录或成稿导出。

IndexedDB 是浏览器替这个站点保存在电脑上的数据库，不在项目文件夹里。正常关闭网页、创作站、Codex 或 PowerShell 不会清除已保存数据；无痕窗口、清除站点数据、换浏览器或换地址可能无法恢复。当前没有云同步，推送 GitHub 也不备份这些运行数据。

## 9. 常见问题

| 现象 | 处理 |
| --- | --- |
| 看不到待确认档案 | 到“我的账号”的“账号档案审核”看具体状态；只同步列表不会产生分析，分析失败先处理本区原因，成功后再确认正式版本 |
| 正文读取返回非 JSON、404 或提示旧后台 | 先保存，停止原启动窗口再启动新版并刷新；随后重试读取。若提示服务版本不匹配，此时通常不需要重新登录 |
| 未登录、需要验证或限流 | 按提示先在终端登录或处理验证，适当等待后主动重试；不会自动反复请求 |
| 访问上下文过期 | 热门参考重新搜索；账号作品按页面重新读取。保留已读内容，必要时手动补正文 |
| 模型超时 | 每次最多 15 分钟；账号可复用已读正文重试分析，也可减少样本或换文案通道。没有自动重试 |
| 仍在旧的约 3 分钟时限报错 | 保存后停止旧服务再启动，仅刷新前端不足以更新后台 |
| 选题或文案提示素材引用不正确 | 按提示查看第几条候选及原因；模型须使用已勾选素材的完整编号，同一素材可用于多个候选。原文与已有结果会保留，处理后再主动重试；升级后仍只有旧提示时，先保存并重启创作站后台 |
| 重启后数据似乎不见了 | 检查浏览器、普通 / 无痕窗口、地址和端口是否一致；固定使用 127.0.0.1:52880，localhost 与其他端口属于不同存储位置 |
| 头像还是占位 | 重启新版服务后重新读取并确认资料，检查公开图片是否加载成功；不必重建账号分析 |

最早的内存版无法找回当时未保存的候选；首次升级会沿用旧的人设、关键词、撰写思路和模型配置。需要进一步排查时，结合具体错误码阅读开发指南，并把实际验证结果更新到 TASK_STATE。
